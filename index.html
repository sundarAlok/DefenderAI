01 · Quest Proposal

Make cyber defense a measurable intelligence market.

DefenderAI is a Bittensor subnet for decentralized cyber-threat detection and operational triage. Sanitized security artifacts—such as URLs, domains, file metadata, network-flow features, authentication anomalies, and threat reports—are turned into structured evaluation tasks. Independent miners run different detection models and return a threat label, confidence, evidence, severity and recommended response. Validators query multiple miners, compare outputs with hidden benchmark labels and adversarial variants, and score precision/recall, false-positive control, robustness, evidence quality, severity calibration and latency. Validators then submit miner weights; Bittensor's consensus and emissions mechanisms aggregate these signals so consistently useful intelligence earns stronger rewards.

The Problem

Security teams face huge volumes of alerts, rapidly changing attack patterns and fragmented detection systems. A single model can become stale, overfit to known indicators, or generate expensive false positives. What is missing is a competitive, continuously tested intelligence layer that can combine specialized detectors without depending on one provider.

The Solution

DefenderAI turns detection into an objective competition. Miners specialize in different threat classes; validators hide evaluation data, inject hard negatives and adversarial mutations, measure real performance, and convert quality into weight signals. The result is a continuously improving marketplace for security intelligence.

04 · Anti-Gaming

Built to make cheating expensive.

Rotating hidden sets

Prevents miners from hard-coding public benchmark answers.

Hard-negative sampling

Measures whether a detector can separate benign activity from real threats.

Adversarial mutations

Tests robustness against altered indicators and distribution shifts.

Cross-validator sampling

Reduces dependence on a single validator's local benchmark.

Evidence checks

Discourages confident labels unsupported by meaningful signals.

Latency normalization

Rewards useful speed without making raw hardware speed the whole game.

Why Bittensor

The problem becomes stronger when intelligence is decentralized.

  • Model diversity: independent miners can specialize instead of forcing one architecture to do everything.
  • Judge diversity: multiple validators provide independent measurements of quality.
  • Economic selection: strong performance is connected to weight signals and emissions.
  • Adaptation: miners are pressured to improve as hidden tests and threats change.
  • Composability: validated outputs can feed SOC workflows, dashboards and security APIs.
